# Reviewer audit of P0 (`git diff 1a56f72..414c7b7`, docs/ excluded)

> Produced by the **reviewer** agent on 2026-10-09. Condensed; findings, evidence and fixes are kept in full.

`npm run check` passes (tsc clean, ESLint clean with `--max-warnings 0`, Vitest 47 passed / 7 skipped as planned).

**Verdict:** two things must be fixed before P0 is done: a behaviour regression in `js/vcf.js`, and several ways to bypass the new HTML sink. The view/`attr.bool` migration itself is clean: 17 captured UI states (every route, goal edit forms, recurrence field toggles, the add-goal `<details>`, disabled reorder buttons, welcome screen) were byte-identical between the old commit and the new one, with no console errors.

## Bugs

1. **HIGH: the BOM regex matches the literal text "FEFF", not the BOM** (`js/vcf.js:173`, `js/vcf.js:198`, commit 414c7b7).
   - `parseVCF('﻿BEGIN:VCARD\nFN:A\nEND:VCARD')` returns 0 contacts (was 1); `parseNameList('FEFFAlice')` returns `Alice`. (Confirmed by the main session.)
   - `FileReader.readAsText` strips a UTF-8 BOM, so file imports are mostly protected; pasted text and other callers are not.
   - Fix: `text.replace(/^﻿/, '')` in both places, after a failing test: `parseVCF('﻿' + sample).length === 3` and `parseNameList('FEFFAlice')[0].fullName === 'FEFFAlice'`.

## Security: the sink is not yet the only way in

2. **HIGH: SafeHtml can be forged via its constructor** (`js/ui/html.js:571-582`): `new (html``.constructor)('<img onerror=…>')`, or `Object.create(proto)` with `.s` set. Fix: a private `WeakSet` of minted, frozen objects; `fmt` and `parseSafe` check membership instead of `instanceof`.
3. **HIGH: SafeHtml is mutable** (`js/ui/html.js:573-574`): `h.s = '<img onerror=…>'` gets through. Fix: `Object.freeze` (covered by #2).
4. **MEDIUM: `html` callable as a plain function** (`js/ui/html.js:602`): `html(['<img …>'])` returns SafeHtml. Fix: require a frozen `strings` array with a `raw` array; lint `CallExpression[callee.name='html']` outside `html.js`.
5. **MEDIUM: `attr.bool` doesn't validate the attribute name** (`js/ui/html.js:617`): `attr.bool('x onmouseover=alert(4)', true)` injects. Fix: allow only `checked, selected, disabled, hidden, open, required, readonly, multiple`.
6. **LOW: lint misses other HTML sinks** (`eslint.config.js:4`): `Object.assign(el, {innerHTML})`, `document.write`/`writeln`, `createContextualFragment`, `DOMParser.parseFromString`, `setHTMLUnsafe`. Fix: add them to `no-restricted-properties`, plus a `Property[key.name=/^(innerHTML|outerHTML)$/]` selector.
7. **LOW:** the `raw` import ban can never fire (`raw` isn't exported). Harmless; not real protection.

Escaping itself is correct: `esc` covers `& < > " '`, all interpolated attributes are double-quoted, data-derived `href`s have fixed prefixes.
