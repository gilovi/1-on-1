מה האפליקציה עושה

"שיחות אישיות" היא אפליקציית ווב למחנכים לניהול שיחות אישיות עם תלמידים: רשימת תלמידים, סיכומי מפגשים, נושאים לשיחה, מטרות ותזמון מפגשים.

איפה נשמר המידע

  • כל המידע נשמר רק ב-Google Drive של המשתמש, בתיקייה שהאפליקציה יוצרת, ובמכשיר של המשתמש (זיכרון הדפדפן) לצורך עבודה רציפה.
  • לאפליקציה אין שרת. המידע לא נשלח, לא נאסף ולא נשמר אצל מפתחי האפליקציה או אצל צד שלישי כלשהו מלבד Google.
  • במצב ניסיון המידע נשמר בדפדפן בלבד.

הרשאות Google

האפליקציה מבקשת את ההרשאה https://www.googleapis.com/auth/drive.file בלבד – גישה לקבצים שהאפליקציה עצמה יצרה. אין לה גישה לשאר הקבצים ב-Drive. ההרשאה משמשת רק ליצירת התיקייה, לקריאה ולשמירה של קובץ הנתונים ולשמירת גיבויים יומיים באותה תיקייה, ולהצגת כתובת הדוא"ל של החשבון המחובר.

השימוש במידע שמתקבל מ-Google APIs עומד בGoogle API Services User Data Policy, כולל דרישות ה-Limited Use.

מחיקת מידע

אפשר למחוק את כל המידע בכל עת על ידי מחיקת התיקייה מ-Google Drive. ניתוק האפליקציה מהחשבון: בכתובת myaccount.google.com/permissions, או בכפתור "התנתקות" בהגדרות האפליקציה.

אחריות המשתמש

המידע עשוי לכלול פרטים אישיים על תלמידים. המחנך אחראי לשימוש במידע בהתאם לנהלי מוסד החינוך ולדין החל.

Privacy Policy (English)

"One-on-one" (שיחות אישיות) is a web app that helps teachers manage personal meetings with their students.

  • Storage: all data is stored only in the user's own Google Drive, in a folder created by the app, and cached in the user's browser. The app has no server; the developers never receive, collect or store any user data, and no data is shared with third parties other than Google.
  • Google permissions: the app requests only the drive.file scope (access to files the app itself created). It is used solely to create the app folder, read and write the app's data file and daily backups, and display the signed-in account's email address.
  • Limited Use: the app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion: delete the app folder from Google Drive to remove all data, and revoke access at myaccount.google.com/permissions.
